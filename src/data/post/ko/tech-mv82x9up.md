금요일 오후 4시 50분, 주말 배포를 앞두고 메인 데스크탑을 켰는데 본체 쿨러는 제트기 엔진 마냥 굉음을 내며 돌아가는데 모니터는 끝까지 'No Signal'을 띄우더라. 팀장님은 5분 뒤에 최종 산출물 확인하자고 스윽 다가오는데, 등줄기에 식은땀이 쫙 흐르면서 뇌가 하얘지는 그 기분, 다들 겪어봤을 거다. 이리저리 케이블을 뽑았다 꽂아봐도 무소용. 결국 출근길 메신저로 연차를 고민하게 만드는 이 개떡 같은 상황, 8년 차 엔지니어인 내가 사내 대나무숲에 푸는 심폐소생술 썰이자 완벽한 기술 랩 리포트로 종결해 준다.

### Step 1. 왜 맨날 멀쩡하던 컴퓨터가 갑자기 이 지랄일까? (근본 원인 분석)

사내 헬프데스크나 인프라 룸에서 맨날 접하는 건데, 컴퓨터가 안 켜지거나 화면이 안 나오는 건 십중팔구 아래 세 가지 중 하나다.

1. 미세한 산화막 및 먼지 유입 (Gold Finger Oxidation): 메인보드 슬롯과 RAM 기판 하단의 금도금 핀(골드핑거) 사이에 공기 중 산소나 습기로 인해 보이지 않는 산화막이 껴서 전기적 신호(Data Signal)가 통하지 않는 현상이다.

2. 열팽창·수축에 따른 물리적 유격 (Thermal Expansion): 겨울철이나 여름철 에어컨 바람 때문에 본체 내부 온도 스펙트럼이 급격히 변하면서, 메인보드 기판과 RAM 슬롯 락(Lock) 장치가 미세하게 뒤틀려 핀 접촉이 살짝 떠버리는 경우다.

3. 정전기 및 미주전류 잔류 (Static / Residual Current): 메인보드 캐패시터에 잔류 전류가 남아있어 보호 회로가 작동, RAM이나 그래픽카드 전원 라인을 차단해 버리는 지독한 상태다.

### Step 2. 삽질은 그만, 5분 만에 끝내는 실전 응급 처치 가이드

자, 당황하지 말고 아래 순서대로 본체를 까자. 드라이버 하나면 충분하다.

<div style="border-left: 4px solid #1e40af; padding: 12px 16px; margin: 20px 0; background-color: rgba(30,64,175,0.05); border-radius: 4px; color: #111827;">
<strong>⚠️ 엔지니어 긴급 경고 (Safety First)</strong><br>
작업 전 반드시 <strong>멀티탭 전원을 끄고 파워서플라이 후면의 물리 스위치를 OFF</strong>로 놓아라. 메인보드에 잔류 전기가 남은 상태에서 RAM을 뽑으면 억 소리 나는 메인보드 쇼트(Short)로 이어져 부품 날려먹기 딱 좋다.
</div>

1단계: 완전 방전 및 본체 오픈
파워 케이블을 완전히 뽑은 상태에서 본체 전원 버튼을 10초 동안 3~4번 눌러 메인보드 캐패시터에 남은 잔류 전류를 완전히 방전시켜라. 그리고 우측/좌측 사이드 패널을 연다.

2단계: RAM 탈거 및 골드핑거 클리닝 (지우개 신공의 진실)
RAM 슬롯 양쪽의 고정 락(Latch)을 바깥쪽으로 딸깍 소리가 날 때까지 누른다. RAM이 살짝 튀어나오면 수직으로 곱게 뽑아낸다.
* 꿀팁: 흔히 미술용 지우개로 골드핑거 부분을 박박 문지르는데, 너무 세게 문지르면 금도금이 벗겨진다. 부드러운 천이나 면봉에 무수소 이소프로필 알코올(IPA)을 살짝 묻혀 핀 부식을 닦아내거나, 깨끗한 지우개로 결이 상하지 않게 한 방향으로 살살 밀어준 뒤 미세 부스러기를 완벽히 털어내야 한다.

3단계: 슬롯 교차 검증 (Slot Cross-Check)
듀얼 채널(2번, 4번 슬롯 등)로 꽂혀 있었다면, 이번엔 1번이나 3번 슬롯으로 자리를 바꿔서 꽂아보자. 메인보드 슬롯 자체의 불량인지, RAM 기판 문제인지 진단하는 가장 확실한 방법이다. 장착할 때는 "딱-" 소리가 양쪽에서 확실히 날 때까지 아래로 강하게 눌러줘야 한다. 락이 저절로 잠기는지 눈으로 확인하자.

### Step 3. 윈도우 부팅 후 확인해야 할 필수 시스템 점검 명령어

어찌저찌 화면이 들어와서 윈도우 진입에 성공했다면, 하드웨어가 정상 인식되었는지 팩트 체크를 해야 한다. 사내 엔지니어들이 현업에서 쓰는 CLI/GUI 점검 루틴이다.

1. 메모리 정상 인식 여부 확인 (GUI):- 단축키 `Ctrl + Shift + Esc`를 눌러작업 관리자 실행 ->성능탭 ->메모리 클릭. 

   - 여기에 장착된 용량(예: 16GB, 32GB)이 풀로 잡혀 있는지, 속도가 정상 표시되는지 확인한다.

2. 시스템 안정성 검사 (CLI - 명령 프롬프트):- 시작 메뉴 검색창에 `cmd` 입력 후 관리자 권한으로 실행.

   - 아래 명령어를 입력하여 윈도우 시스템 파일 무결성을 점검한다.
     ```cmd
     DISM.exe /Online /Cleanup-image /Restorehealth
     sfc /scannow
     ```

3. Windows 메모리 진단 도구 실행:

   - 시작 메뉴에 `Windows 메모리 진단` 검색 후 실행.
   - "지금 다시 시작하여 문제 확인(권장)"을 눌러 재부팅되면서 RAM 불량 섹터가 있는지 정밀 검사를 돌린다. (이때 에러 코드가 뜨면 RAM 교체 각이다.)

## 5. 자주 묻는 질문 (FAQ)

**Q1.** 지우개로 닦았는데도 계속 화면이 안 들어오고 본체에서 '삑-삑-삑' 비프음이 납니다.

**A1.** 비프음은 BIOS의 POST(Power-On Self-Test) 에러 코드다. RAM이 슬롯에 완전히 결합되지 않았거나, RAM 갯수가 여러 개인 경우하나씩만 꽂아서어느 녀석이 뻗었는지(사망 판정) 개별 테스트를 해봐야 한다.

**Q2.** 슬롯을 바꿨는데도 컴퓨터가 무한 재부팅(부팅 루프)에 빠집니다.

**A2.** RAM 접촉 불량 외에도 메인보드 CMOS 설정이 꼬였을 확률이 높다. 본체 전원을 끄고 메인보드 수은 전지(CR2032)를 5분간 뺐다가 다시 끼워CMOS 초기화(Clear CMOS)를 진행해 보라.

**Q3.** 램 오버클럭(XMP/EXPO)을 쓰는데 이 증상이 자주 발생합니다.

**A3.** 오버클럭 세팅이 안정적이지 못해 메인보드가 부팅 실패를 감지하고 안전 모드로 진입하려는 신호일 수 있다. 이 경우 부팅 성공 후 바이오스에 들어가서 램 전압을 살짝 올려주거나 클럭을 한 단계 낮춰 안정화 작업을 다시 거쳐야 한다.
