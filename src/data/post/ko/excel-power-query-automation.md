"야, 김대리. 전국 12개 지점 지난달 매출 데이터 취합 아직 안 끝났어? 임원 회의 20분 전인데?"

마감 날 오후 5시 40분. 메신저 창에 팀장의 빨간색 느낌표가 깜빡일 때마다 등줄기에서 식은땀이 주르륵 흐릅니다. 모니터에는 각 지점에서 보내온 엑셀 파일 12개가 너저분하게 열려 있고, 내 손가락은 영혼 없이 `Ctrl + C`, `Ctrl + V`를 미친 듯이 반복하고 있죠. 

더 끔찍한 건 꼭 이런 순간에 부산 지점 파일에서 열 순서가 바뀌어 있거나, 대구 지점 시트의 날짜 형식이 깨져 있다는 겁니다. 복사해서 붙여넣다가 수식이 꼬여 `#REF!` 에러가 뜨는 순간, 속으로 외치게 됩니다. 

*'아, 오늘 저녁 약속도 날아갔구나...'*

만약 여러분도 매월 말마다 이런 '엑셀 노가다' 때문에 야근을 밥 먹듯이 하고 있다면, 지금 당장 복사 붙여넣기를 멈추세요. 파워 쿼리(Power Query)를 쓰면 **새로운 엑셀 파일을 특정 폴더에 그냥 던져 넣고 [새로 고침] 버튼 딱 한 번 누르는 것만으로 수십 개 시트 취합이 1초 만에 끝납니다.**

---

### 파워 쿼리가 도대체 뭔데 야근을 없애줄까?

파워 쿼리는 엑셀 2016 버전 이상부터 기본 탑재된 **'데이터 정제 및 자동 변환 엔진'**입니다. 어렵게 생각할 것 전혀 없습니다. 우리가 엑셀에서 손으로 일일이 하던 다음 작업들을 매크로나 코딩(VBA) 없이 그대로 녹화해 주는 똑똑한 비서라고 보시면 됩니다.

1. **여러 파일 불러오기**: 지정된 폴더 안의 모든 엑셀 문서를 한 번에 읽어옵니다.
2. **불필요한 데이터 걸러내기**: 첫 줄 빈칸 제거, 제목 행 올리기, 합계 행 지우기를 자동으로 처리합니다.
3. **규격 통일하기**: 텍스트로 저장된 숫자를 진짜 숫자로 바꾸고 날짜 형식을 표준화합니다.
4. **하나로 합치기**: 규격이 맞춰진 수만 줄의 데이터를 아래로 깔끔하게 이어 붙입니다.

한 번 이 작업 흐름을 설정해 두면, 다음 달에는 **새 파일만 폴더에 넣고 [모두 새로 고침]을 누르는 순간 모든 작업이 0.1초 만에 자동 재생**됩니다.

---

### 실전 3분 세팅: 폴더 내 엑셀 파일 자동 취합 4단계

직접 따라 해보실 수 있도록 가장 흔한 '지점별 월간 매출 취합'을 기준으로 핵심 단계만 정리해 드립니다.

#### 1단계: 취합용 전용 폴더 만들기
바탕화면이나 사내 드라이브에 `월별매출취합`이라는 폴더를 하나 만듭니다. 그리고 각 지점에서 보내온 엑셀 파일들을 이 폴더 안에 전부 집어넣습니다.

#### 2단계: 엑셀에서 폴더 데이터 불러오기
1. 깨끗한 새 엑셀 파일을 엽니다.
2. 상단 메뉴에서 **[데이터]** $\rightarrow$ **[데이터 가져오기]** $\rightarrow$ **[파일에서]** $\rightarrow$ **[폴더에서]**를 클릭합니다.
3. 아까 만들어둔 `월별매출취합` 폴더를 선택하고 **[열기]**를 누릅니다.

#### 3단계: 데이터 결합 및 변환
1. 팝업 창이 뜨면 폴더 내 파일 목록이 보입니다. 여기서 우측 하단의 **[결합]** 옆 작은 화살표를 눌러 **[데이터 결합 및 변환]**을 선택합니다.
2. 첫 번째 샘플 파일을 기준으로 취합할 시트(예: `Sheet1` 또는 `매출내역`)를 선택하고 확인을 누르면 **파워 쿼리 편집기** 창이 열립니다.
3. 상단 메뉴를 보면서 불필요한 열을 마우스 우클릭으로 제거하거나, 열 머리글을 깔끔하게 정리해 줍니다. (이때 수행한 모든 수정 작업은 우측 '적용된 단계'에 자동으로 영구 저장됩니다.)

#### 4단계: 엑셀로 닫기 및 로드
편집이 끝났다면 좌측 상단의 **[닫기 및 로드]**를 클릭합니다. 
수십 개 파일로 흩어져 있던 데이터가 하나의 완벽한 표(Table)로 엑셀 시트에 순식간에 정리되어 쏟아져 나옵니다.

---

### 다음 달부터 칼퇴하는 마법의 버튼

다음 달이 되면 어떻게 하면 될까요? 다시 파워 쿼리를 만들 필요가 전혀 없습니다.

1. 새로 받은 다음 달 엑셀 파일들을 그냥 그 폴더에 넣습니다.
2. 취합본 엑셀을 열고 **[데이터]** 탭 $\rightarrow$ **[모두 새로 고침]** (단축키: `Ctrl + Alt + F5`)을 누릅니다.
3. 끝입니다. 폴더에 새로 들어온 파일들까지 자동으로 규칙에 맞춰 취합 완료됩니다.

---

### 실무에서 자주 겪는 주의점 2가지

1. **열 이름(헤더)은 같아야 합니다**: 파워 쿼리는 열 머리글(예: `날짜`, `매출액`, `지점명`)을 기준으로 데이터를 합칩니다. 지점마다 한 곳은 `매출액`, 다른 곳은 `판매금액`이라고 쓰여 있으면 서로 다른 열로 분리되니 양식의 머리글 이름은 통일해 두는 것이 좋습니다.
2. **원본 파일이 열려 있으면 에러가 납니다**: 폴더 안에 있는 개별 파일이 누군가의 PC나 내 엑셀에서 열려 있으면 파일 잠금 때문에 새로 고침 시 오류가 발생할 수 있습니다. 취합 전 파일들을 닫아두세요.
