### 왜 내 C드라이브는 항상 꽉 차는 걸까요? (근본 원인 분석)

윈도우 11을 쾌적하게 쓰다 보면 어느 날 갑자기 용량이 증발해 있는 현상을 겪게 됩니다. 사내 동료들의 PC를 점검하며 발견한 대표적인 3가지 원인은 다음과 같습니다.

1. 방치된 윈도우 업데이트 및 시스템 임시 파일 (`Temp`, `SoftwareDistribution`)

   대규모 보안 패치나 기능 업데이트가 진행될 때마다 기존 OS 파일의 백업본과 다운로드 캐시가 고스란히 쌓입니다. 시간이 지나면 수십 기가바이트에 달하는 정크 데이터로 변합니다.

2. 개발 툴 및 브라우저 캐시의 폭발적인 증가

   크롬, 엣지 등의 웹 브라우저 캐시뿐만 아니라, 윈도우 스토어 앱 데이터, 그리고 개발자들의 경우 노드 모듈(`node_modules`), 도커 이미지 레이어, 윈도우 하위 시스템(WSL2) 가상 disk 파일이 C드라이브의 숨통을 조입니다.

3. **최대 절전 모드** 파일(`hiberfil.sys`)과 가상 메모리(`pagefile.sys`)

   이 파일들은 사용자의 물리 램(RAM) 용량과 맞물려 자동으로 생성되는데, 32GB 램을 사용하는 머신의 경우 **최대 절전 모드** 파일만으로도 C드라이브 용량을 20GB 이상 고정적으로 차지하게 됩니다.

### 실무자가 검증한 C드라이브 용량 확보 4단계 솔루션

자, 이제 본격적으로 윈도우 11 기본 기능과 안전한 도구를 이용해 C드라이브를 다이어트 시켜 보겠습니다. 관리자 권한과 시스템 설정 메뉴를 적극적으로 활용합니다.

## 1단계: 윈도우 11 '저장소 센스' 및 추천 정리 활용하기
무작정 폴더를 뒤지기 전에 윈도우가 제공하는 공식 청소 기능을 쓰는 것이 가장 안전합니다.

* `설정` (Win + I) > `시스템` > `저장소`로 이동합니다.
* 상단에 표시되는 C드라이브 분석 결과를 잠시 기다린 후, [임시 파일] 메뉴를 클릭합니다.
* 스캔이 완료되면 다운로드 폴더, 이전 윈도우 설치 파일, 윈도우 업데이트 정리 등 삭제 가능한 항목 리스트가 나타납니다.
* 주의:'다운로드' 폴더는 본인이 저장해 둔 소중한 파일이 있을 수 있으니 체크 해제하시고, [이전 Windows 설치], [Windows 업데이트 정리], [임시 파일] 위주로 체크한 뒤 [파일 제거]를 누릅니다.

## 2단계: 안전하게 시스템 임시 파일 및 캐시 수동 정리하기
저장소 센스로 잡히지 않는 깊은 곳의 찌꺼기들을 정리할 차례입니다.

* 키보드의 `Win + R`을 눌러 실행 창을 엽니다.
* `temp`를 입력하고 엔터를 칩니다. 열린 폴더 안의 파일들을 전체 선택(`Ctrl + A`) 후 삭제(`Shift + Del`)합니다. (현재 실행 중인 프로그램이 사용하는 파일은 "건너뛰기"가 뜨니 무시하셔도 됩니다.)
* 다시 `Win + R`을 누르고 `%temp%`를 입력하여 나타나는 사용자별 임시 파일 폴더도 동일하게 비워줍니다.
* 마지막으로 `prefetch`를 입력하여 나타나는 부팅 프리페치 파일들도 깔끔하게 지워줍니다. 시스템 속도가 체감할 정도로 빨라집니다.

## 3단계: 디스크 정리(Cleanmgr)로 시스템 파일 깊은 곳까지 청소하기
윈도우 전통의 강력한 유틸리티인 디스크 정리를 관리자 권한으로 실행합니다.

* 작업 표시줄 검색창에 `디스크 정리`를 검색한 뒤, [관리자 권한으로 실행]을 선택합니다.
* 드라이브 선택 창에서 `C:`를 선택하고 확인을 누릅니다.
* 창이 뜨면 하단의 [시스템 파일 정리] 버튼을 다시 클릭합니다. (이 과정에서 권한 확인 창이 뜨면 승인합니다.)
* 다시 계산이 끝난 후 나타나는 목록에서 [Windows 업데이트 정리], [이전 Windows 설치], [시스템 오류 메모리 덤프 파일] 등에 체크하고 확인을 누릅니다. 수기가바이트에서 수십 기가바이트의 공간이 마법처럼 확보됩니다.

## 4단계: WinDirStat 또는 WizTree로 대용량 범인 색출하기
텍스트나 기본 설정만으로는 도저히 어디서 용량을 잡아먹는지 모를 때 사용하는 실무 필살기입니다.

* 무료 디스크 분석 프로그램인 WizTree(또는 WinDirStat)를 다운로드하여 설치 후 실행합니다.
* C드라이브를 스캔하면 블록 형태의 시각적 그래픽과 함께 어떤 폴더가 가장 많은 용량을 차지하고 있는지 한눈에 파악할 수 있습니다.
* 흔히 발생하는 범인인 `C:\Users\[사용자명]\AppData\Local` 안의 거대한 캐시 폴더들이나 대형 로그 파일을 찾아 안전하게 정리합니다.

### 전문가 조언 및 향후 예방 가이드

C드라이브 용량 부족 문제는 한 번 해결했다고 끝이 아닙니다. 몇 달 지나면 캐시 데이터로 다시 꽉 차기 마련이죠. 이를 방지하기 위한 몇 가지 실무 팁을 공유합니다.

* 대용량 파일 저장 위치 변경: 카카오톡, 텔레그램, 토렌트 등 다운로드 경로를 C드라이브가 아닌 D나 E 등 여유 있는 데이터 드라이브로 사전에 변경해 두세요.
* 가상 메모리(Pagefile) 재배치: 물리 램이 32GB 이상으로 넉넉하다면 C드라이브의 가상 메모리 크기를 적절히 제한하거나 다른 드라이브로 할당하는 것도 방법입니다.
* 정기적인 저장소 센스 자동화: 윈도우 설정에서 저장소 센스를 '켜짐'으로 해두고, 매주 또는 매월 자동으로 임시 파일을 정리하도록 설정해 두면 출근길에 C드라이브 경고로 스트레스받을 일이 사라집니다.

### 자주 묻는 질문 (FAQ)

**Q1.** 임시 파일(`Temp`)이나 프리페치 파일을 지우면 컴퓨터가 고장 나지 않나요?

A1. 전혀 고장 나지 않습니다! 이 폴더들은 프로그램들이 실행 중에 임시로 데이터를 적어두는 '메모장' 같은 역할입니다. 프로그램을 닫은 후에는 아무 쓸모가 없는 찌꺼기들이므로 안심하고 삭제하셔도 시스템 동작에 전혀 지장을 주지 않습니다.

**Q2. **'이전 Windows 설치(Windows.old)' 폴더는 왜 생기며 지워도 안전한가요?

A2. 윈도우 대규모 업데이트(예: 윈도우 11 빌드 업그레이드) 직후, 업데이트에 문제가 생겼을 때 이전 버전으로 안전하게 롤백할 수 있도록 임시로 보관하는 백업 폴더입니다. 시스템이 안정적으로 잘 작동하고 있다면 디스크 정리를 통해 과감히 삭제하셔도 무방합니다.

**Q3.** C드라이브 용량을 늘리기 위해 파티션을 조정하고 싶은데 위험하지 않나요?

A3. 윈도우 기본 '디스크 관리'나 서드파티 파티션 관리 툴(예: MiniTool Partition Wizard)을 이용해 인접한 D드라이브의 공간을 떼어와 C드라이브를 확장하는 것은 가능합니다. 하지만 작업 중 전원 차단이나 오류 발생 시 데이터 손실 위험이 있으므로, 파티션 조작 전에는 반드시 중요한 데이터를 외장 하드나 클라우드에 백업하고 진행하시는 것을 강력히 권장합니다.
