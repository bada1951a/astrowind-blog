안녕하세요! 동네 컴퓨터 수리점 10년 차, 여러분의 든든한 기술 주치의 '테크닥터'입니다.

매일 컴퓨터로 업무를 시작하려는데 마우스를 아래로 가져가도 아무 반응이 없고, 윈도우 로고가 그려진 시작 버튼을 클릭해도 묵묵부답일 때가 있으신가요? 시계도 멈춰 있는 것 같고, 열려 있는 브라우저는 움직이는데 하단 바 전체가 얼어붙은 듯한 그 답답함, 저도 수리 현장에서 수백 번은 마주친 흔한 증상입니다.

보통 이럴 때 많은 분들이 당황해서 본체 전원 버튼을 냅다 길게 눌러 강제로 꺼버리곤 하십니다. 하지만 10년 동안 수많은 고장 PC를 고쳐온 제 입장에서 솔직히 말씀드리면, **강제 종료는 PC의 뼈와 살을 갉아먹는 가장 위험한 행동**입니다. 전자기기를 강제로 끄는 건, 전력 질주로 달리던 사람의 발을 갑자기 걸어 넘어뜨리는 것과 같거든요.

오늘은 초보자분들도 소중한 데이터 손실 걱정 없이 100% 안전하게 따라 할 수 있는 '무위험 복원 가이드'를 준비했습니다. 천천히 저를 따라와 보세요.

## 0단계: 안전제일! 작업 중인 데이터와 비상 단축키 챙기기

시작 버튼이 눌리지 않아도 키보드는 여전히 살아있는 경우가 대부분입니다. 본격적인 수술에 들어가기 전에, 최소한의 안전장치를 챙겨야 합니다.

![컴퓨터 앞에서 문제 해결을 고민하는 모습](https://images.unsplash.com/photo-1517694712202-14dd9538aa97?auto=format&fit=crop&w=1200&q=80)

### 1) 열려 있는 문서 저장하기
작업 표시줄이 멈췄더라도 작성 중이던 엑셀이나 한글, 워드 창이 띄워져 있다면 해당 창을 클릭한 뒤 키보드의 **`Ctrl + S`**를 눌러 작업을 먼저 저장하세요. 창 전환이 안 된다면 **`Alt + Tab`**을 눌러 원하는 창으로 이동할 수 있습니다.

### 2) 안전 종료 단축키 기억하기
만약 컴퓨터를 꼭 재부팅해야 한다면 전원 버튼을 누르지 마시고, 키보드의 **`Windows 로고 키 + X`**를 누른 다음, 키보드 방향키나 알파벳 **`U`**를 두 번 연속 눌러보세요. 윈도우의 정상적인 시스템 종료 절차를 밟아 안전하게 꺼집니다.

## 1단계: 가장 가벼운 심폐소생술, 'Windows 탐색기' 깨우기

작업 표시줄과 시작 버튼은 윈도우 안에서 **'Windows 탐색기(explorer.exe)'**라는 비서가 담당하고 있습니다. 이 비서가 과로로 잠깐 기절한 상태라고 생각하시면 됩니다. 비서를 깨워 업무를 다시 맡겨보겠습니다.

솔직히 말씀드리면, **수리점에 입고되는 작업 표시줄 먹통 증상의 70%는 이 1단계만으로 깔끔하게 해결**됩니다.

1. 키보드에서 **`Ctrl + Shift + Esc`** 키를 동시에 누릅니다. (한 손으로 누르기 쉬운 단축키이며, 누르면 즉시 **'작업 관리자'** 창이 나타납니다.)
2. 화면에 작업 관리자가 뜨면, 만약 창이 작게 보일 경우 좌측 하단의 '자세히'를 눌러 화면을 넓혀줍니다.
3. '프로세스' 탭 목록을 아래로 천천히 스크롤 하여 노란색 폴더 아이콘 모양을 한 **'Windows 탐색기'** 항목을 찾습니다.
4. 해당 항목에 마우스 오른쪽 버튼을 클릭하고 **'다시 시작'**을 누릅니다.

화면이 1~2초 정도 깜빡이면서 작업 표시줄이 사라졌다가 다시 짠하고 나타날 것입니다. 이제 시작 버튼을 마우스로 콕 눌러보세요. 정상적으로 팝업 메뉴가 올라온다면 가벼운 일시적 충돌이었으니 안심하셔도 좋습니다.

## 2단계: 시스템 파일의 상처 치료하기 (SFC 및 DISM 검사)

탐색기를 다시 띄웠는데도 여전히 시작 버튼이 먹통이거나 클릭 후 모래시계만 돈다면, 윈도우의 핵심 시스템 파일 일부가 손상되었을 가능성이 높습니다. 

명령어 창(검은 화면)을 열어야 해서 무서워 보일 수 있지만, 윈도우 자체 진료 프로그램이라 부작용이 전혀 없는 안전한 방법입니다.

![안전한 시스템 점검과 터미널 작업](https://images.unsplash.com/photo-1550751827-4bd374c3f58b?auto=format&fit=crop&w=1200&q=80)

1. 키보드의 **`Ctrl + Shift + Esc`**를 눌러 다시 **'작업 관리자'**를 엽니다.
2. 상단 메뉴에서 **'파일'** -> **'새 작업 실행'**을 클릭합니다.
3. 입력창이 나오면 **`cmd`**라고 적고, 반드시 바로 아래에 있는 **'관리자 권한으로 이 작업 실행'** 체크박스에 체크한 뒤 확인을 누릅니다.
4. 검은색 명령 프롬프트 창이 뜨면 아래 명령어를 한 글자씩 정확히 입력하거나 복사해 붙여넣고 엔터를 칩니다.

```text
DISM.exe /Online /Cleanup-image /Restorehealth
```

이 작업은 마이크로소프트 공식 서버에서 원본 정상 파일을 받아와 깨진 부품을 교체하는 과정입니다. 인터넷 속도와 PC 성능에 따라 5분에서 15분 정도 걸릴 수 있으니 느긋하게 차 한잔 마시며 기다려보세요. 

완료 문구가 뜨면, 연이어 아래 명령어를 입력하고 엔터를 칩니다.

```text
sfc /scannow
```

시스템 전체를 꼼꼼히 훑어 손상된 파일이 있다면 자동으로 수리해 줍니다. "손상된 파일을 발견하고 성공적으로 복구했습니다"라는 메시지가 나오면 컴퓨터를 한 번 재부팅해 줍니다.

## 3단계: 엉켜버린 윈도우 앱 패키지 재등록하기

윈도우 10과 11의 시작 메뉴와 작업 표시줄은 스마트폰의 '기본 앱'처럼 구동됩니다. 종종 윈도우 자동 업데이트 도중에 앱 구성 파일 간의 연결 고리가 꼬여버리면 겉으로는 정상처럼 보여도 클릭이 되지 않는 이상 현상이 일어납니다.

이 꼬인 실타래를 한 번에 풀어주는 방법입니다.

1. 앞서 배운 대로 **`Ctrl + Shift + Esc`**로 작업 관리자를 엽니다.
2. **'파일'** -> **'새 작업 실행'**을 누르고, 이번에는 **`powershell`**이라고 적습니다.
3. 마찬가지로 **'관리자 권한으로 이 작업 실행'**에 꼭 체크하고 확인을 누릅니다.
4. 파란색 화면(PowerShell)이 나타나면 아래의 긴 명령어를 통째로 복사해서 창 안에 마우스 오른쪽 버튼을 찰칵 눌러 붙여넣은 뒤 엔터를 칩니다.

```powershell
Get-AppXPackage -AllUsers | Foreach {Add-AppxPackage -DisableDevelopmentMode -Register "$($_.InstallLocation)\AppXManifest.xml"}
```

화면 상단에 노란색, 초록색 진행 바가 빠르게 지나가며 윈도우의 모든 기본 앱을 제자리에 다시 꽂아 넣습니다. 빨간색 경고 문구가 몇 줄 스쳐 지나갈 수 있는데, 이미 사용 중인 앱이라 건너뛰는 정상적인 반응이니 놀라지 마세요. 

작업이 끝나고 커서가 깜빡거리면 창을 닫고 재부팅을 진행해 봅니다.

## 10년 차 테크닥터의 솔직한 조언과 예방법

마지막으로 제가 현장에서 일하며 뼈저리게 느낀 점 두 가지를 솔직하게 털어놓고 싶습니다.

첫째, **인터넷에 떠도는 '원클릭 PC 최적화 프로그램'이나 레지스트리 청소기는 제발 쓰지 마세요.**  
시작 버튼 오류로 매장에 찾아오시는 손님들의 PC를 열어보면 열에 아홉은 이름 모를 무료 클리너가 깔려 있습니다. 이 프로그램들이 '불필요한 찌꺼기 파일'이라며 윈도우 시작 메뉴의 필수 캐시 파일까지 지워버려 이 사달이 나는 경우가 정말 많습니다. 윈도우 10과 11은 자체 최적화 기능만으로도 충분히 똑똑합니다.

둘째, **시스템 복원 지점을 평소에 꼭 켜두시길 권장합니다.**  
윈도우 검색창이 살아났을 때 `'복원 지점 만들기'`를 검색하셔서, C 드라이브의 보호 설정이 '설정'으로 되어 있는지 꼭 확인해 보세요. 이 기능 하나만 켜두셔도 나중에 어떤 치명적인 오류가 발생하든 어제, 혹은 그저께의 멀쩡했던 상태로 컴퓨터를 타임머신 태워 돌려보낼 수 있습니다.

오늘 알려드린 1단계(탐색기 재시작)부터 3단계(PowerShell 재등록)까지 차근차근 진행하셨다면, 대부분의 먹통 현상은 마법처럼 풀렸을 것입니다. 컴퓨터는 기계일 뿐이니 조금 삐걱거리더라도 겁먹지 마시고 부드럽게 달래주세요.

혹시 이 모든 과정을 거쳤는데도 증상이 해결되지 않는다면 댓글로 여러분의 윈도우 버전과 증상을 편하게 남겨주세요. 테크닥터가 추가 진단을 도와드리겠습니다!
