144Hz나 240Hz 고주사율 게이밍 모니터를 구매하고도 본체에 연결만 한 채 기본 60Hz 상태로 사용하는 경우가 매우 많습니다. 모니터는 전원을 연결한다고 해서 자동으로 최고 주사율로 동작하지 않으며, **윈도우 디스플레이 설정과 올바른 케이블 연결**이 반드시 필요합니다.

화면이 부드럽지 않거나 설정 메뉴에서 60Hz만 보일 때 즉시 해결하는 3단계 가이드를 정리해 드립니다.

---

## 1. 윈도우 11/10에서 144Hz 활성화하는 방법

컴퓨터 기본 설정에서 주사율이 60Hz로 제한되어 있는지 가장 먼저 확인해야 합니다.

1. 바탕화면 빈 곳을 마우스 우클릭한 뒤 **[디스플레이 설정]**을 클릭합니다.
2. 화면을 아래로 내려 **[고급 디스플레이]**로 들어갑니다.
3. 여러 모니터를 쓰고 있다면 상단에서 게이밍 모니터를 선택합니다.
4. 하단의 **'새로 고침 빈도 선택(주사율)'** 드롭다운 메뉴를 클릭하고 **144Hz(또는 지원하는 최대 수치)**를 선택합니다.
5. 화면이 잠시 깜빡인 후 나타나는 확인 창에서 **[변경 내용 유지]**를 누르면 설정이 완료됩니다.

---

## 2. 144Hz 옵션이 안 뜰 때: 케이블 규격 체크

설정 창에 60Hz만 표시된다면 십중팔구 **케이블 규격 또는 연결 단자 문제**입니다.

| 케이블 종류 | 권장 규격 | 최대 지원 주사율 (FHD/QHD 기준) | 특징 및 추천 |
| :--- | :--- | :--- | :--- |
| **DP (DisplayPort)** | DP 1.2 이상 (권장 1.4) | 144Hz ~ 240Hz 이상 완벽 지원 | **PC 게이밍 시 가장 추천하는 케이블** |
| **HDMI** | HDMI 2.0 이상 | 구형 케이블(1.4 이하)은 60Hz~120Hz 제한 | 그래픽카드 및 모니터 포트 버전 확인 필수 |

* **외장 그래픽카드 직결 확인**: 메인보드 내장 단자가 아닌 본체 아래쪽 **외장 그래픽카드(지포스/라데온) 단자**에 케이블을 꽂았는지 확인하세요.
* **DP 케이블 권장**: 고주사율과 지싱크(G-Sync), 프리싱크(FreeSync) 기능을 온전히 쓰려면 HDMI보다는 **DP 케이블 연결**이 가장 안정적입니다.

---

## 3. 엔비디아(NVIDIA) 제어판 추가 점검

지포스 그래픽카드를 사용 중이라면 엔비디아 제어판 해상도 설정도 함께 확인해야 합니다.

1. 바탕화면 우클릭 $\rightarrow$ **[NVIDIA 제어판]** 실행
2. 왼쪽 메뉴의 **[디스플레이]** $\rightarrow$ **[해상도 변경]** 클릭
3. 해상도 목록에서 위쪽 'Ultra HD, HD, SD' 항목 대신 스크롤을 내려 **'PC' 섹션 아래의 해상도**를 선택합니다.
4. 우측의 **'재생 빈도'** 목록에서 144Hz 이상을 선택한 뒤 하단 **[적용]**을 누릅니다.

## 4. 정상 작동 확인 팁

설정을 마친 후 인터넷 브라우저에서 **[testufo.com](https://www.testufo.com)**에 접속해 보세요. 
화면 상단에 현재 모니터가 감지한 실제 주사율(144 fps / 144 Hz)이 초록색으로 표시되면 완벽하게 적용된 것입니다.
