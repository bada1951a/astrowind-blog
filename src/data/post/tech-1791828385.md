## 윈도우11 시스템 지연의 핵심 증상 및 기술적 원인 분석

윈도우11은 사용자 인터페이스(UI)의 심미성을 높이기 위해 'Mica(마이카)' 및 'Acrylic(아크릴)' 머티리얼 기반의 반투명 블러 효과, 둥근 모서리 앤티앨리어싱, 동적 애니메이션을 대거 도입했습니다. 그러나 이 기능들은 데스크톱 창 관리자(Desktop Window Manager, `dwm.exe`) 프로세스의 VRAM 점유율과 GPU 렌더링 파이프라인 부담을 기하급수적으로 늘리는 주범입니다. 

고사양 외장 그래픽 카드를 탑재한 시스템이라도 다중 모니터 환경이나 고주사율(144Hz 이상) 게이밍 환경에서는 DWM 스레드 병목으로 인해 1% Low 프레임 드랍(스터터링)이 빈번하게 발생합니다. 특히 CPU 내장 그래픽(iGPU)을 주력으로 사용하는 사무용 노트북이나 UMPC, 미니 PC 환경에서는 메인 시스템 메모리(DDR4/DDR5)의 대역폭을 GPU와 공유(UMA 구조)하기 때문에, 시각 효과 연산만으로도 메모리 버스 경합이 발생하여 시스템 전체의 I/O 응답 지연을 초래합니다.

소프트웨어적 관점에서는 윈도우 10 대비 변경된 윈도우 11의 UWP(유니버설 윈도우 플랫폼) 백그라운드 정책이 문제를 가중시킵니다. 윈도우 10은 '설정 > 개인 정보 > 백그라운드 앱' 메뉴를 통해 모든 앱의 백그라운드 실행을 한 번에 토글(Toggle) 스위치로 차단할 수 있었습니다. 반면 윈도우 11은 일괄 비활성화 메뉴가 삭제되고 각 설치된 앱의 세부 설정이나 그룹 정책(Group Policy), 패키지 수명 주기 관리자(PLM) 설정을 통해서만 개별 제어되도록 설계가 변경되었습니다. 

이로 인해 사용자가 인지하지 못하는 사이 날씨, 위젯, 피드백 허브, 마이크로소프트 뉴스, 엑스박스 관련 서비스 등이 메모리에 상주하며 텔레메트리(진단 데이터) 전송, 주기적 네트워크 풀링(Polling), 캐시 갱신 작업을 수행합니다. 이는 시스템 유휴(Idle) 상태에서도 CPU의 C-State(절전 상태) 진입을 지속해서 방해하여 불필요한 전력 소모와 스로틀링(Throttling)을 유발합니다.

## 단계별 해결 가이드

### 1단계: 불필요한 시각 효과 및 투명도 완전 튜닝

화려한 효과를 제거하여 DWM 프로세스의 GPU/RAM 점유율을 즉시 회수하고 입력 지연(Input Latency)을 줄입니다.

1. **고급 시스템 속성 실행**:
   - 단축키 `Windows 키 + R`을 눌러 실행 창을 엽니다.
   - `sysdm.cpl`을 입력하고 엔터를 누릅니다.
2. **성능 옵션 세부 설정**:
   - 상단 탭에서 **[고급]**을 선택하고 성능 항목의 **[설정(S)...]** 버튼을 클릭합니다.
   - **[사용자 지정(C)]**을 선택한 뒤, 모든 체크 박스를 해제합니다.
   - 단, 가독성과 실용성을 위해 **반드시 아래 4가지 항목만 다시 체크**합니다:
     - `마우스 포인터 아래 그림자 표시` (선택 사항)
     - `아이콘 대신 미디엄/라지 아이콘에 미리 보기 표시` (사진 작업 시 필수)
     - `화면 글꼴의 가장자리 다듬기` (ClearType 폰트 깨짐 방지 필수)
     - `마우스로 끄는 동안 창 내용 표시` (창 이동 시 프레임 확인용)
   - **[적용]** 후 **[확인]**을 클릭합니다.
3. **윈도우11 투명도 효과 끄기**:
   - `Windows 키 + I`를 눌러 **[설정]**으로 이동합니다.
   - **[접근성]** > **[시각 효과]** 탭으로 진입합니다.
   - **[투명도 효과]** 토글을 **[끔]**으로 변경합니다.
   - **[애니메이션 효과]** 역시 **[끔]**으로 변경하여 즉각적인 창 전환 속도를 확보합니다.

### 2단계: UWP 백그라운드 앱 일괄 차단 (그룹 정책 및 레지스트리)

윈도우 11 환경에서 모든 앱의 백그라운드 작동을 근본적으로 차단하는 전문가 수준의 설정법입니다.

#### A. Windows 11 Pro / Enterprise / Education (로컬 그룹 정책 편집기)
1. `Windows 키 + R`을 누르고 `gpedit.msc`를 입력하여 실행합니다.
2. 좌측 탐색 트리에서 다음 경로로 이동합니다:
   - `컴퓨터 구성` > `관리 템플릿` > `Windows 구성 요소` > `앱 프라이버시(App Privacy)`
3. 우측 정책 목록에서 **[Windows 앱이 백그라운드에서 실행되도록 허용(Let Windows apps run in the background)]** 항목을 찾아 더블 클릭합니다.
4. 옵션을 **[사용(E)]**으로 변경합니다.
5. 좌측 하단 '모든 앱에 대한 기본값' 드롭다운 메뉴에서 **[사용자가 제어할 수 없음 - 강제로 거부(Force Deny)]**를 선택합니다.
6. **[적용]** 및 **[확인]**을 누르고 시스템을 재부팅합니다.

#### B. Windows 11 Home (레지스트리 직접 제어)
그룹 정책 편집기가 없는 Home 에디션은 관리자 권한 명령 프롬프트를 통해 동일한 정책 키를 주입합니다.

1. `Windows 키 + S`를 누르고 `cmd`를 검색한 뒤 **[관리자 권한으로 실행]**을 클릭합니다.
2. 아래 명령어를 그대로 복사하여 콘솔 창에 붙여넣고 엔터를 누릅니다:
   ```cmd
   reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows\AppPrivacy" /v "LetAppsRunInBackground" /t REG_DWORD /d 2 /f
   ```
   *(값 데이터 `2`는 '강제로 거부'를 의미합니다. 원상 복구를 원할 경우 끝의 숫자를 `0`으로 수정하여 다시 실행하면 됩니다.)*

### 3단계: 시작 프로그램 및 작업 스케줄러 찌꺼기 프로세스 정리

백그라운드에서 주기적으로 리소스를 점유하는 제3자(Third-party) 소프트웨어 자동 실행을 중단합니다.

1. **작업 관리자를 통한 시작 프로그램 관리**:
   - `Ctrl + Shift + Esc`를 눌러 작업 관리자를 호출합니다.
   - 좌측 네비게이션에서 **[시작 앱]** 아이콘을 클릭합니다.
   - 상태가 **[사용]**으로 되어 있는 항목 중 필수적인 백신 드라이버(예: Realtek, Windows Security)를 제외한 상용 메신저, 클라우드 동기화 툴(OneDrive, Google Drive 등), 게임 런처(Steam, Riot Client)를 우클릭하여 **[사용 안 함]**으로 전환합니다.
2. **서비스 구성 다이어트**:
   - `Windows 키 + R`을 누르고 `msconfig`를 입력합니다.
   - **[서비스]** 탭으로 이동한 뒤, 하단의 **[모든 Microsoft 서비스 숨기기(H)]** 체크 박스를 **반드시 먼저 활성화**합니다.
   - 목록에 남은 서드파티 서비스 중 원격 제어, 미사용 업데이트 서비스(Adobe Update, Chrome Elevation 등)의 체크를 해제하고 **[적용]**을 누릅니다.

## 실무자 팁 및 주의사항

현업에서 원격 및 출장 트러블슈팅을 진행할 때, 사용자들이 성능을 극대화하겠다며 성능 옵션에서 무턱대고 **'최적 성능으로 조정'** 라디오 버튼을 누르고 전체 항목을 해제하는 실수를 대단히 많이 목격합니다. 이 경우 **'화면 글꼴의 가장자리 다듬기(ClearType)'** 서브픽셀 렌더링 엔진까지 완전히 꺼지게 됩니다. 

결과적으로 4K나 QHD 해상도를 사용하는 최신 고해상도 모니터에서도 웹서핑 및 문서 작업 시 폰트가 1990년대 도스 시절처럼 심하게 깨져 극심한 눈의 피로와 두통을 유발합니다. 절감되는 성능 차이는 벤치마크 오차 범위 수준인 0.1% 미만이므로, 폰트 다듬기 기능은 절대 끄지 마십시오.

또한, 백그라운드 앱을 그룹 정책의 `Force Deny` 값으로 일괄 차단할 경우 알림 인프라(WNS)에 영향을 미칠 수 있습니다. Microsoft Store를 통한 필수 시스템 구성 요소(예: 삼성 Magician, Dell Command Update, 오디오 제어판 등 하드웨어 전용 제어 앱)가 백그라운드 장치 폴링을 하지 못해 하드웨어 특수 기능 키(Fn 키) 반응이 지연될 수 있습니다. 

따라서 브랜드 노트북을 사용하는 환경이라면 일괄 레지스트리 차단보다는 '설정 > 앱 > 설치된 앱' 메뉴에서 제조사 제어 센터를 제외한 소비성 앱(TikTok, Xbox, 뉴스 등)만 선별하여 **'백그라운드 앱 사용 권한: 안 함'**으로 지정하는 점진적 접근법을 권장합니다.

## 자주 묻는 질문 (FAQ)

### Q1. 백그라운드 앱을 끄면 카카오톡, 텔레그램, 디스코드 같은 메신저 알림도 안 오나요?
**A:** 일반적인 데스크톱 Win32 프로그램(카카오톡 PC 버전, 디스코드 독립 설치 파일 등)은 마이크로소프트의 UWP 백그라운드 통제를 받지 않습니다. 이 가이드에서 다룬 백그라운드 앱 비활성화는 Microsoft Store에서 내려받은 UWP 패키지 기반 앱에만 적용됩니다. 따라서 독립 실행형 Win32 메신저 프로그램은 정상적으로 백그라운드 트레이에 상주하며 실시간 알림을 보냅니다. 단, 시작 프로그램에서 해당 앱을 '사용 안 함'으로 설정했다면 윈도우 부팅 후 프로그램을 수동으로 한 번은 실행해야 알림을 받을 수 있습니다.

### Q2. 윈도우11 '위젯(Widgets)' 작업 표시줄 아이콘만 끄면 백그라운드 리소스 소모가 멈추나요?
**A:** 단순히 작업 표시줄 설정에서 위젯 스위치를 '끔'으로 변경하는 것은 화면에서 아이콘을 숨길 뿐, 백그라운드의 `Widgets.exe` 프로세스와 연동된 웹뷰2(Edge WebView2) 런타임의 램 상주를 완벽히 막지 못합니다. 위젯 엔진을 완전히 동결시키려면 로컬 그룹 정책 편집기(`gpedit.msc`)에서 `컴퓨터 구성` > `관리 템플릿` > `Windows 구성 요소` > `위젯` 경로의 **[위젯 허용]** 정책을 **[사용 안 함]**으로 구성해야 메모리 누수를 완전히 원천 차단할 수 있습니다.

### Q3. 시각 효과 최적화 작업을 완료한 후 원래 윈도우11 기본값으로 되돌리려면 어떻게 해야 하나요?
**A:** 복구 방법은 매우 직관적입니다. `sysdm.cpl` 실행 후 성능 옵션에서 **[내 컴퓨터에 가장 좋은 설정을 자동으로 선택(L)]**을 클릭하고 적용하면 운영체제가 하드웨어 사양을 감지하여 시각 효과를 기본 구성으로 롤백합니다. 또한 비활성화했던 투명도 및 애니메이션 효과는 `Windows 설정 > 접근성 > 시각 효과`에서 두 토글 스위치를 다시 [켬]으로 켜주면 즉시 초기 상태의 미려한 UI로 복귀됩니다. 레지스트리 변경 사항 역시 2단계에서 언급한 값을 `0`으로 재입력하거나 생성한 `AppPrivacy` 키를 삭제하면 초기화됩니다.
