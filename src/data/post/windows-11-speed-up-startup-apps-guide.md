새 컴퓨터나 노트북을 구매했을 때는 번개처럼 빠르던 윈도우 11이 몇 달 사용하다 보면 부팅 후 마우스 커서가 멈칫거리거나 버벅거리는 현상을 겪게 됩니다.

그 주된 원인은 프로그램을 설치할 때마다 나도 모르게 **'윈도우 시작 시 자동 실행'**으로 등록된 백그라운드 상주 프로그램들 때문입니다. 별도의 최적화 유틸리티 설치 없이 윈도우 자체 설정만으로 부팅 및 작업 체감 속도를 빠르게 만드는 핵심 꿀팁을 정리해 드립니다.

---

## 1. 시작프로그램 정리 (부팅 체감 속도 1위)

윈도우가 켜질 때 백그라운드에서 동시에 실행되는 프로그램이 많을수록 CPU와 메모리 점유율을 잡아먹습니다.

### 설정 방법:
1. 키보드의 **`Ctrl + Shift + Esc`** 키를 동시에 눌러 **[작업 관리자]**를 엽니다.
2. 왼쪽 메뉴에서 시계 계기판 모양의 **[시작 앱]** 아이콘을 클릭합니다.
3. 목록에서 **'시작 영향'** 열을 확인합니다. ('높음'으로 표시된 항목이 범인입니다.)
4. 메신저(카카오톡, 디스코드), 웹하드 클라우드, 게임 런처(스팀, 라이엇), 프린터 보조 프로그램 등 **부팅 직후 바로 쓸 필요가 없는 프로그램**을 마우스 우클릭 후 **[사용 안 함]**으로 변경합니다.

> **주의할 점**: 백신 프로그램(Windows Defender, 안랩 등)이나 오디오 드라이버(Realtek) 관련 항목은 그대로 **[사용]** 상태로 두셔야 합니다.

---

## 2. 불필요한 백그라운드 앱 실행 차단

백그라운드에서 주기적으로 리소스를 소모하는 기본 앱들의 동작을 차단하면 메모리 확보에 매우 효과적입니다.

1. **`윈도우 키 + I`**를 눌러 **[설정]** 창을 엽니다.
2. **[앱]** $\rightarrow$ **[설치된 앱]**으로 이동합니다.
3. 잘 쓰지 않는 기본 앱(예: 지도, 날씨, 뉴스 등) 오른쪽의 **`···` (더 보기)** 버튼을 누르고 **[고급 옵션]**을 선택합니다.
4. **'백그라운드 앱 권한'** 항목을 찾아 옵션을 **[안 함]**으로 변경합니다.

---

## 3. 고속 부팅(빠른 시작 켜기) 상태 점검

윈도우 11에는 종료 전 세션 정보를 저장해 다음 부팅 속도를 단축시키는 **'빠른 시작'** 기능이 있습니다. 간혹 이 기능이 꺼져 있어 부팅이 느려질 수 있습니다.

1. `윈도우 키 + R`을 누르고 `control`을 입력해 **[제어판]**을 엽니다.
2. **[전원 옵션]** $\rightarrow$ 좌측 **[전원 단추 작동 설정]**을 클릭합니다.
3. 상단의 **'현재 사용할 수 없는 설정 변경'**을 클릭해 잠금을 해제합니다.
4. 하단 종료 설정에서 **[빠른 시작 켜기(권장)]**에 체크가 되어 있는지 확인 후 저장합니다.

---

## 4. 임시 파일 및 캐시 청소 (디스크 공간 확보)

1. **`윈도우 키 + I`** $\rightarrow$ **[시스템]** $\rightarrow$ **[저장소]**로 이동합니다.
2. **[임시 파일]** 항목을 클릭합니다.
3. 이전 윈도우 업데이트 설치 파일, 임시 인터넷 파일, 휴지통 파일 등을 체크하고 **[파일 제거]**를 클릭합니다.

---

## 요약 정리

1. **작업 관리자**에서 시작 영향 '높음' 앱들 `사용 안 함` 처리
2. 사용 빈도가 낮은 앱의 **백그라운드 권한** 차단
3. 한 달에 한 번 **임시 파일 청소**

이 3가지만 주기적으로 점검해도 별도의 유료 프로그램 없이 윈도우 11을 언제나 쾌적하고 빠른 상태로 유지할 수 있습니다.
