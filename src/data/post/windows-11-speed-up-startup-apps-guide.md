컴퓨터를 처음 샀을 때와 달리, 사용 시간이 지나면서 부팅 시간이 점점 길어지고 바탕화면이 뜬 뒤에도 마우스 커서가 멈칫거리는 현상을 겪게 됩니다.

대부분의 원인은 사용자가 모르는 사이에 설치된 프로그램들이 윈도우 시작과 동시에 백그라운드에서 실행되기 때문입니다. 윈도우 11 기본 설정을 통해 불필요한 시작 앱을 정리하고 부팅 속도를 최적화하는 핵심 가이드를 정리해 드립니다.

---

## 1. 작업 관리자에서 시작 프로그램 비활성화

부팅 속도에 가장 직접적인 영향을 주는 기능입니다.

1. 키보드 단축키 **`Ctrl + Shift + Esc`**를 눌러 **작업 관리자**를 엽니다.
2. 왼쪽 메뉴에서 **[시작 앱]** (속도계 또는 시작 프로그램 모양 아이콘)을 클릭합니다.
3. 목록에서 **'시작 시 영향'** 열을 확인합니다:
   * **높음**: 부팅 시 시스템 자원을 많이 소모하는 프로그램입니다.
4. 사용하지 않는 메신저, 클라우드 동기화 툴, 보안 프로그램 등을 마우스 우클릭한 뒤 **[사용 안 함]**으로 변경합니다.
   * *주의: 오디오 드라이버(Realtek)나 그래픽 제어판(NVIDIA/Intel)은 '사용' 상태로 유지합니다.*

---

## 2. 윈도우 11 설정에서 백그라운드 앱 사용 권한 제한

앱이 백그라운드에서 상시 실행되며 램(RAM)과 CPU를 점유하는 것을 방지합니다.

1. **`Win + I`**를 눌러 **설정**을 엽니다.
2. **[앱]** $\rightarrow$ **[설치된 앱]**으로 이동합니다.
3. 백그라운드 실행이 필요 없는 앱(날씨, 지도, 뉴스, 각종 보조 유틸리티 등) 오른쪽의 **`···`** 아이콘 클릭 후 **[고급 옵션]**을 선택합니다.
4. **'백그라운드 앱 사용 권한'** 항목을 찾아 **[안 함]**으로 변경합니다.

---

## 3. 고속 시작(Fast Startup) 활성화 상태 점검

윈도우 11의 빠른 시작 켜기는 부팅 시간을 단축시키는 유용한 기능이지만, SSD 환경에서 간혹 시스템 충돌을 유발하기도 합니다.

1. **`Win + R`**을 누르고 `control`을 입력해 **제어판**을 엽니다.
2. **[전원 옵션]** $\rightarrow$ **[전원 단추 작동 설정]**을 클릭합니다.
3. 상단의 **'현재 사용할 수 없는 설정 변경'**을 클릭한 뒤, 아래쪽 종료 설정에서 **'빠른 시작 켜기(권장)'**에 체크가 되어 있는지 확인합니다.

---

## 4. 정기적인 관리 팁

* 사용하지 않는 프로그램은 시작 프로그램 끄기에 그치지 않고 **설정 $\rightarrow$ 설치된 앱**에서 완전히 제거합니다.
* 주기적으로 **임시 파일 정리(저장소 센스)**를 켜두면 디스크 읽기/쓰기 병목 현상을 방지할 수 있습니다.
