## 1. 職場で冷や汗をかいた緊急トラブル

丸の内のオフィスで、お気に入りのカフェラテを片手にランチ休憩から席に戻ってきた。よし、午後の最初の業務を始めようとTeamsのビデオ会議を開いた瞬間――相手の声が全く聞こえない。「あれっ？」と思い、YouTubeで音声をテストしても無音のまま。タスクバーのスピーカーアイコンには無情にも小さなバツ印やミュートのマークがついている。午後イチの重要ミーティングまであと15分しかない。この冷や汗が出るようなシチュエーション、皆さんも経験したことがあるのではないだろうか。

現場で数多くのPCトラブルを見てきた私だが、昼休み明けの音声トラブルは非常に多い。スリープ復帰時のドライバの誤作動や、Bluetoothイヤホンとの接続競合など、原因は様々だ。慌てて再起動をする前に、まずは落ち着いて原因を切り分け、最短で音を取り戻すためのステップを踏んでいこう。

Windows 11で音が出なくなる3つの主な原因

なぜ、さっきまで正常に出ていた音が突然消えてしまうのだろうか。現場で遭遇するトラブルの大部分は、以下の3つのいずれかに集約される。

1. オーディオ出力先の誤選択・デフォルトデバイスの喪失

   スリープからの復帰時に、外部モニターのスピーカーや、前回接続していたBluetoothヘッドセットへと出力先が勝手に切り替わってしまい、実際には音が出ていない状態。

2. オーディオドライバーの一時的なクラッシュ（WdAudioやRealtekの停止）

   Windows Updateのバックグラウンド実行や省電力機能の誤作動により、サウンドドライバがフリーズまたは無効化されているケース。

3. Windowsサービス（Windows Audio）の停止

   オーディオを統括するシステムサービスそのものが何らかの理由で停止している場合。

実践！最短で音声を復活させるステップ・バイ・ステップ解決法

ここからは、実際に現場で使っている手際の良いトラブルシューティング手順を解説する。順番に試していけば、ほとんどの音響トラブルは数分で解決できる。

ステップ1: 出力デバイスと音量ミキサーの確認（[設定]からのアプローチ）

まずは、音の出口が正しく指定されているか確認する。

1. スタートボタンをクリックし、[設定]を開く。

## 2. [システム] ＞ [サウンド] の順にクリックする。

3. 「出力」セクションで、現在使用しているスピーカーやヘッドホンが正しく選択されているか確認する。

4. もし別のデバイスが選ばれていた場合は、正しいデバイスをクリックして切り替える。

5. 同画面内の「音量ミキサー」を開き、各アプリケーション（Teamsやブラウザなど）の個別音量がミュートになっていないかチェックする。

ステップ2: ドライバーの状態確認と再読み込み（[デバイスマネージャー]の活用）

出力先が正しいにもかかわらず音が出ない場合は、ドライバーの不具合を疑う。

1. スタートボタンを右クリックし、メニューから[デバイスマネージャー]を選択する。

2. リストの中から「サウンド、ビデオおよびゲーム コントローラー」をダブルクリックして展開する。

3. 使用しているオーディオデバイス（例: Realtek Audio や インテル 智慧音效技術 など）を右クリックする。

4. まずは[デバイスの無効化]を押し、数秒待ってからもう一度右クリックして[デバイスの有効化]を選択する。これだけでドライバーが再読み込みされ、音が戻ることが多々ある。

5. それでもダメな場合は、右クリックして[ドライバーの更新]を選び、「ドライバーを自動的に検索」を実行する。

```cmd
参考：管理者権限のコマンドプロンプトでオーディオサービスを再起動するコマンド
net stop Audiosrv
net start Audiosrv
```

ステップ3: [コントロールパネル]での詳細なサウンド設定確認

Windows 11の新しい設定画面で解決しない古風かつ確実な方法として、伝統的なコントロールパネルを活用する。

1. タスクバーの検索ボックスに `コントロール パネル` と入力して開く。

2. 表示方法を「大きいアイコン」に変更し、[サウンド]をクリックする。

3. 「再生」タブを開き、普段使っているスピーカーやヘッドホンを右クリックして[既定のデバイスに設定]を選ぶ。

4. そのデバイスをダブルクリックして「プロパティ」を開き、「レベル」タブでミュートになっていないか、音量が下がっていないかを確認する。

5. 「空間オーディオ」タブがある場合は、一度別の設定に変えるかオフにしてみることで、ドライバの競合が解消されることがある。

プロが教えるハードウェア・電源管理の注意点

ノートPC（特にビジネス向けのLet's noteやThinkPad、Latitudeなど）で頻発するのが、省電力機能によるオーディオチップの電源切断だ。
デバイスマネージャーのオーディオデバイスのプロパティから「電源の管理」タブ（存在する場合）を開き、「電力の節約のために、コンピューターでこのデバイスの電源をオフにできるようにする」のチェックを外すことで、スリープ復帰後の音出ない病を予防できる。

## 5. よくある質問 (FAQ)

**Q1.**Bluetoothイヤホンを接続した途端にPC全体の音が出なくなりました。

**A1.**Bluetoothプロファイルの競合が原因のことが多いです。アクションセンターから一度Bluetoothを完全にオフにし、再度オンにするか、[設定] ＞ [Bluetooth とデバイス] から一度デバイスを削除してペアリングし直してください。

**Q2.**「オーディオサービスが応答していません」というエラーが出ます。

**A2.**Windowsのオーディオ関連サービスが停止しています。タスクマネージャー（[タスクマネージャー]）を開き、「サービス」タブから `Audiosrv` や `AudioEndpointBuilder` を探し、右クリックして「サービスを開始」または「再起動」を選択してください。

**Q3.**イヤホンジャックに物理的に挿しているのに、内蔵スピーカーから音が出ます。

**A3.** イヤホン端子内部のスイッチが物理的に固着しているか、Realtekオーディオコンソールなどのユーティリティアプリ側でジャック挿入時の動作設定が狂っている可能性があります。オーディオマネージャーアプリの設定を確認するか、優しくジャックを抜き差ししてみてください。
