새 외장하드나 외장 SSD, USB 메모리를 컴퓨터에 연결해 포맷 창을 띄우면 가장 먼저 마주치는 선택지가 바로 **파일 시스템(NTFS, exFAT, FAT32)**입니다.

"그냥 기본값으로 포맷하면 되는 것 아닌가?" 싶지만, 포맷 방식을 잘못 선택하면 맥북(Mac)에서 파일 복사가 안 되거나, 4GB가 넘는 고화질 영상 파일이 안 들어가는 낭패를 겪을 수 있습니다. 내 사용 환경에 딱 맞는 최적의 포맷 방식을 한눈에 알기 쉽게 정리해 드립니다.

---

## 1. 3대 파일 시스템 한눈에 비교

| 파일 시스템 | 윈도우 호환 | 맥(macOS) 호환 | 단일 파일 최대 크기 | 추천 사용처 |
| :--- | :--- | :--- | :--- | :--- |
| **NTFS** | 읽기/쓰기 완벽 | 읽기만 가능 (기본) | 사실상 무제한 (16TB+) | 윈도우 PC 전용 외장하드/SSD, 안정성 최우선 |
| **exFAT** | 읽기/쓰기 완벽 | 읽기/쓰기 완벽 | 사실상 무제한 (16EB) | 윈도우 + 맥/스마트폰 병용 외장 드라이브 |
| **FAT32** | 읽기/쓰기 완벽 | 읽기/쓰기 완벽 | **최대 4GB 제한** | 차량용 블랙박스, 구형 네비게이션, 오디오 USB |

---

## 2. 각 방식의 장단점과 특징

### ① NTFS (New Technology File System)
윈도우의 표준 기본 파일 시스템입니다.

* **장점:** 
  * '저널링(Journaling)' 기능이 있어 전원 차단이나 갑작스러운 케이블 분리 시 데이터 손상 및 파일 깨짐 위험이 가장 낮습니다.
  * 대용량 파일 복사 및 처리 안정성이 뛰어납니다.
* **단점:**
  * 맥(macOS)에 연결하면 파일 열람(읽기)은 되지만, **새 파일 복사나 수정(쓰기)이 불가능**합니다. (별도 유료 드라이버 프로그램 필요)

### ② exFAT (Extended File Allocation Table)
FAT32의 단점을 보완해 만든 크로스 플랫폼 표준입니다.

* **장점:** 
  * 윈도우와 맥은 물론, 안드로이드 스마트폰/태블릿, 스마트 TV 등 거의 모든 운영체제에서 별도 프로그램 없이 바로 읽고 쓰기가 가능합니다.
  * 단일 파일 4GB 용량 제한이 전혀 없습니다.
* **단점:**
  * NTFS에 비해 저널링 안전장치가 약해, 데이터 전송 중 케이블을 그냥 뽑아버리면 파일 테이블이 `RAW` 상태로 깨질 위험이 상대적으로 높습니다.
  * **Tip:** exFAT 드라이브는 반드시 작업 표시줄의 **[하드웨어 안전하게 제거]**를 누른 뒤 분리해야 합니다.

### ③ FAT32 (File Allocation Table 32)
가장 오래된 범용 규격입니다.

* **특징:** 호환성은 최고 수준이지만 **단일 파일 용량이 4GB로 제한**됩니다. 10GB짜리 영화 파일이나 4K 영상 원본을 복사하려고 하면 "파일이 너무 커서 대상 파일 시스템에 쓸 수 없습니다"라는 에러가 뜹니다.

---

## 3. 상황별 최적의 선택 가이드

* **내가 윈도우 PC만 쓴다**: 무조건 **NTFS**를 추천합니다. 데이터 복구 확률과 안전성이 가장 높습니다.
* **윈도우 PC와 맥북(Mac)을 번갈아 가며 쓴다**: 무조건 **exFAT**을 선택하세요.
* **차량용 음악 USB, 블랙박스, 구형 콘솔 게임기용이다**: 장비 매뉴얼에서 요구하는 **FAT32**로 포맷해야 인식됩니다.

---

## 4. 윈도우에서 외장하드 포맷하는 초간단 방법

1. `내 PC`(파일 탐색기)를 엽니다.
2. 포맷하려는 외장 드라이브 아이콘을 **우클릭** $\rightarrow$ **[포맷(A)...]**을 클릭합니다.
3. **파일 시스템** 드롭다운에서 본인에게 맞는 방식(`NTFS` 또는 `exFAT`)을 선택합니다.
4. **할당 단위 크기**: 건드리지 않고 **기본 할당 크기**로 둡니다.
5. **볼륨 레이블**: 원하는 드라이브 이름(예: `MySSD`, `BackupHDD`)을 적어줍니다.
6. **포맷 옵션**: `빠른 포맷`에 체크한 상태에서 **[시작]**을 누르면 수 초 내로 완료됩니다.
